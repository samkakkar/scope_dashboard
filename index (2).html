Data Format Guide

Your file can be a single-sheet Excel workbook (.xlsx). The parser will look for a header row containing Year in School (or just Year) to auto-detect the layout - so the header doesn't have to be in row 1. Columns can be in any order.

Column nameWhat to enterRequired?
Year in School Freshman, Sophomore, Junior, Senior, or Graduate Yes
Major Full major name, e.g. "Computer Science" or "Industrial Engineering" Yes
GPA Number between 0.0 and 4.0, e.g. 3.75 Optional
Final Acceptances (or Accepted) Put the accepted person's name here (or "Yes"). Leave blank if not accepted. Optional
Example row (all columns):
Sophomore | Industrial Engineering | 3.82 | Priya Sharma
File naming: Name your file with the semester and year so insights update automatically.
Examples: Spring2027.xlsx, Fall2027.xlsx, Spring_2027.xlsx, fall 2027.xlsx
The dashboard reads the semester name from the filename - if it can't detect one, it will label the upload "New Semester" with the current year.
Tips: The parser recognises common abbreviations (FYE, IBE, BAIM, CS, IE…) and year variants ("5th Year" → Senior, "Graduate Student" → Graduate). Column headers can have extra words - "What is your current GPA out of 4.00?" is still detected as GPA. The file can have many extra columns; they are ignored.
